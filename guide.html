Goal: Pass CCA-F in 2 weeks (3-week fallback included) Status: 75% on first practice test Completed: Building with the Claude API

Exam facts — know these before you schedule

  • Format: 60 scenario-based multiple-choice questions, 4 options, 1 correct.
  • Time: 120 minutes (2 min/question — a comfortable pace).
  • Pass mark: 720 / 1000 — a scaled score, not a raw percentage. A real passer scored 44/60 (73% raw) → 738, one wrong answer from failing. Aim for ~80%+ raw for margin.
  • No penalty for guessing — answer every question, never leave one blank.
  • Delivery: Online proctored or Pearson VUE center. Closed-book, no AI assistance.
  • Cost: ~$125 / attempt (Exam Guide v0.2, June 30 2026).

Do this today

Register and lock a test date for the end of Week 2. A committed date is the single biggest driver of finishing on time — and this cert is tied to your promotion.

The exam's hidden grading logic — memorize these tiebreakers

Every question shows 3–4 plausible answers. When stuck, the "architecturally correct" choice almost always follows these:

  • Simplest robust solution wins — don't add a subagent / classifier / memory layer a scenario doesn't need.
  • Better tool description before a routing classifier.
  • Programmatic enforcement before a stronger prompt (validate/retry in code > "ask nicely").
  • Explicit context passing before a shared memory layer.
  • Escalate to a human at defined thresholds rather than letting an agent guess on low confidence.
  • Use stop_reason to control loop flow — never a fixed loop count.
Week 1Repair the weak domains
Days 1–3 · Agentic Architecture & Orchestration — 27%, weakest
CourseIntroduction to Subagents (Anthropic Academy)
DocsClaude Agent SDK overview · Building with Claude

Master these

  • Agentic loop + stop_reason: tool_use → run tool, append result, loop back; end_turn → done, exit; max_tokens → truncated, handle it. Most "broken loop" scenarios are mishandled stop_reason.
  • One loop vs. subagents — the core judgment call. Subagents for (a) context isolation, (b) parallel independent subtasks, (c) specialization. Single loop when linear and small — over-decomposing adds latency, tokens, failure points.
  • Hub-and-spoke / orchestrator-worker: coordinator decomposes → dispatches to workers → synthesizes. Subagents run in their own context window and return a clean summary.
  • Context budgets & delegation: subagents don't inherit the parent's full context; pass scoped context explicitly. Custom agents live in .claude/agents; the SDK uses AgentDefinition.
  • Parallel vs. sequential subagent execution and when each fits.

Self-check: For 5 mini-scenarios, decide single-loop vs. subagents and justify in one sentence.

Days 4–6 · Claude Code Configuration & Workflows — 20%, 2nd weakest
CoursesClaude Code 101 (fast) → Claude Code in Action

Master these

  • CLAUDE.md: what belongs in it, project vs. user scope, how it shapes agent behavior.
  • Slash commands: built-in vs. custom, and where custom commands are defined.
  • Hooks: the lifecycle events, and when a hook is the right enforcement point vs. a prompt instruction.
  • Permissions / settings: allow/deny tooling and how config is resolved.
  • CI/CD & MCP-into-Code: headless/automation patterns and wiring MCP servers into Claude Code.

Self-check: Answer "where would you enforce X?" — CLAUDE.md, a hook, a permission rule, or a slash command — for several examples.

  • Sit a full 60-question / 120-minute test under real conditions (no notes, no AI, timer on).

Day 14 · Light review + EXAM
  • Morning: skim error list and tiebreakers only. No new material.
  • Sit the exam. Answer every question. Flag-and-return anything over ~2 minutes.
